# پنل Onvioo

پنل مدیریت محتوا، مشتریان و تیم Onvioo. نقشه کامل و فازبندی در [سند نیازمندی‌ها](https://claude.ai/code/artifact/e0a70a3d-45c9-4c11-ac2a-045646aedfca) است.

## فاز ۰ (پایه) شامل چه چیزهایی است

- ورود با **کد پیامکی** (کاوه‌نگار) یا **رمز عبور**، با سه نقش: مدیر، کارمند و مشتری
- **مشتریان:** ثبت، ویرایش، وضعیت همکاری و ساختن دسترسی پرتال برای مشتری
- **کارکنان:** افزودن عضو تیم با سمت و نوع حقوق (ماهانه، ساعتی، به‌ازای هر کار)، فعال و غیرفعال کردن
- **فایل‌ها:** آپلود مستقیم ریلز و استوری به فضای ابری S3 (مثل آروان) تا ۵ گیگابایت، با نوار پیشرفت و دانلود امن
- **داشبورد:** مشتری‌های فعال، اعضای تیم و فایل‌های ماه جاری (ماه شمسی)
- **پرتال مشتری:** صفحه ورود جدا برای مشتری (امکاناتش در فاز ۲ اضافه می‌شود)
- ظاهر فارسی راست‌به‌چپ، تاریخ شمسی، تم روشن و تیره، و نصب روی گوشی مثل اپ (PWA)
- ثبت همه تغییرات مهم در جدول `audit_log`

## فاز ۱ (محتوا، تقویم و کارها)

- **بورد محتوا:** مسیر هر ریلز و استوری از ایده تا انتشار در هفت ستون؛ جابه‌جایی با کشیدن کارت (و منوی مرحله روی گوشی)، فیلتر مشتری و مسئول، هشدار عقب‌افتادگی
- **صفحه هر محتوا:** کپشن، هشتگ، مهلت و زمان انتشار، فایل‌های خام و نسخه‌های تدوین (v1، v2…)، نظرها با زمان دقیق در ویدیو، تاریخچه مراحل
- **کارهای خودکار:** رفتن محتوا به تدوین، بازبینی یا آماده انتشار برای مسئولش کار می‌سازد و با رفتن به مرحله بعد می‌بندد؛ برگشت از بازبینی «اعمال اصلاحات» ثبت می‌کند
- **کارها:** کارهای من، همه و انجام‌شده‌ها؛ افزودن سریع با اولویت و مهلت
- **جلسه‌های ضبط:** تاریخ و ساعت، محل، تصویربردار، سناریو و چک‌لیست تجهیزات تیک‌خوردنی، و محتواهای هر جلسه
- **تقویم شمسی:** زمان انتشار محتواها و جلسه‌های ضبط در نمای ماه (و فهرست روزانه روی گوشی)

## فاز ۲ (پرتال مشتری، قرارداد، سایت و تیکت، اعلان‌ها)

- **پرتال مشتری:** مشتری مسیر هر محتوا را می‌بیند، نسخه تدوین را نگاه می‌کند و با یک دکمه تأیید یا با زمان دقیق در ویدیو اصلاحیه می‌خواهد؛ یادداشت‌های «داخلی» تیم به مشتری نشان داده نمی‌شود
- **قرارداد دیجیتال:** ساخت از روی قالب، ارسال برای مشتری، امضا با کد پیامکی؛ نام، شماره، IP، مرورگر و اثر انگشت متن (SHA-256) ثبت می‌شود و نسخه چاپی یا PDF دارد
- **خدمات سایت:** پروژه‌های سایت، فرانت، بک‌اند، سئو و پشتیبانی با مرحله‌ها و درصد پیشرفت که مشتری هم می‌بیند
- **تیکت پشتیبانی:** مشتری تیکت باز می‌کند، تیم جواب می‌دهد، وضعیت باز، پاسخ‌داده و بسته
- **اعلان‌ها:** زنگوله داخل پنل و پرتال، پیامک به مشتری (با `KAVENEGAR_NOTIFY_TEMPLATE`) و پیام به گروه تیم در بله یا تلگرام

## فاز ۳ (هوش رشد)

- **آمار پیج‌ها:** فالوور، بازدید و ریچ روزانه و آمار هر پست، از API رسمی اینستاگرام (Graph API) یا با ورود فایل CSV و ثبت دستی
- **پیش‌بینی رشد:** روند ۹۰ روز اخیر و اینکه هر ریلز اضافه در هفته چقدر فالوور می‌آورد، با نمودار و اسلایدر «ریلز بیشتر»؛ مشتری هم در پرتال می‌بیند
- **امتیاز وایرال:** در صفحه هر محتوا، هوک، کپشن، هشتگ و زمان انتشار با آمار همان پیج و رقبا سنجیده می‌شود، همراه هوک و کپشن پیشنهادی
- **رادار ترند و رقبا:** ایده‌های آماده ضبط از محتوای موفق پیج و رقبا که با یک کلیک به بورد اضافه می‌شوند؛ هشدار وقتی پست رقیب چند برابر معمول بگیرد و تحلیل «چرا گرفت»
- **گزارش هفتگی:** گزارش فارسی هر شنبه، بازبینی تیم، ارسال برای مشتری با پیامک، و نسخه چاپی یا PDF
- **بهترین زمان انتشار:** میانگین بازدید بر اساس ساعت و روز هفته به وقت تهران

کارهای زمان‌بندی‌شده را با cron سرور صدا بزنید:

```bash
# هر روز ساعت ۶ صبح: آمار اینستاگرام
0 6 * * *  curl -fsS -X POST -H "Authorization: Bearer $CRON_SECRET" https://panel.example.com/api/cron/instagram
# شنبه‌ها ساعت ۸: پیش‌نویس گزارش‌های هفتگی
0 8 * * 6  curl -fsS -X POST -H "Authorization: Bearer $CRON_SECRET" https://panel.example.com/api/cron/weekly
```

## فاز ۴ (کارکنان و مالی)

- **حضور و مرخصی:** ثبت ورود و خروج با انتخاب مشتری، جابه‌جایی بین مشتری‌ها، ثبت دستی و بستن بازه‌های فراموش‌شده توسط مدیر، درخواست و تأیید مرخصی
- **حقوق:** فیش ماهانه از روی ساعت کار (ساعتی)، کارهای تحویل‌شده (کارمزدی) یا حقوق ثابت با اضافه‌کار بالای ۱۷۶ ساعت و کسر مرخصی بدون حقوق؛ پاداش و کسورات قابل ویرایش؛ پرداخت از یک حساب که خودش تراکنش حقوق می‌سازد
- **امتیاز تیم:** رتبه‌بندی ماهانه از کار تحویل‌شده، تحویل به‌موقع و ساعت کار
- **مالی:** درآمد و هزینه با دسته‌بندی، هزینه‌های ثابت ماهانه، شرکا (سهم سود، آورده، برداشت)، سود و زیان ماهانه و موجودی حساب‌ها؛ جدا از حسابداری کافه
- **تطبیق بانک:** بارگذاری صورتحساب اکسل یا CSV، حدس ستون‌ها، ریال به تومان، رد سطرهای تکراری، تطبیق خودکار، سه ستون «تطبیق‌شده / فقط در بانک / فقط در پنل»، ثبت یک‌کلیکی با دسته پیشنهادی، مقایسه مانده و قفل دوره
- **ورود دیتای گذشته:** خروجی پارمیس یا هر اکسل با انتخاب ستون‌ها، پیش‌نمایش و برگرداندن کل فایل
- **سودآوری مشتری:** دریافتی هر مشتری منهای هزینه ساعت‌هایی که تیم روی او گذاشته

## فاز ۵ (فروش و عملیات)

- **فاکتور و پرداخت آنلاین:** فاکتور با چند ردیف، تخفیف و مالیات بر ارزش افزوده؛ ساخت از روی قرارداد؛ لینک پرداخت بدون ورود برای مشتری با درگاه زرین‌پال؛ ثبت خودکار دریافتی در مالی بعد از پرداخت؛ ثبت دستی پرداخت کارت‌به‌کارت؛ یادآور پیامکی قبل و بعد از موعد؛ فاکتورها در پرتال مشتری
- **مشتریان بالقوه (CRM):** قیف فروش از «جدید» تا «قرارداد بسته شد»، ثبت تماس و پیام و جلسه، تاریخ پیگیری بعدی و یادآور روزانه به مسئول هر مشتری، دلیل از دست رفتن، تبدیل یک‌کلیکی به مشتری، پیش‌نویس پیام پیگیری با هوش مصنوعی
- **پایش سایت مشتری‌ها:** بررسی هر ۵ دقیقه با زمان پاسخ و کلمه کلیدی صفحه، اعلان قطع و وصل شدن به گروه تیم (بعد از دو خطای پشت‌سرهم)، هشدار انقضای SSL و دامنه، درصد در دسترس بودن ۲۴ ساعت و ۳۰ روز؛ وضعیت سایت در پرتال مشتری
- **دستیار پنل:** گفتگو با Claude درباره کارهای عقب‌افتاده، برنامه انتشار، وضعیت مشتری‌ها و سایت‌ها، پیگیری‌های فروش و (فقط برای مدیر) فاکتورها و سود ماه؛ دستیار فقط می‌خواند و چیزی را تغییر نمی‌دهد

کارهای زمان‌بندی‌شده این فاز:

```cron
# هر ۵ دقیقه: پایش سایت‌ها
*/5 * * * *  curl -fsS -X POST -H "Authorization: Bearer $CRON_SECRET" https://panel.example.com/api/cron/monitor
# هر روز ساعت ۹: یادآور فاکتورها، پیگیری‌های فروش و انقضای دامنه
0 9 * * *    curl -fsS -X POST -H "Authorization: Bearer $CRON_SECRET" https://panel.example.com/api/cron/daily
```

برای پرداخت آنلاین `ZARINPAL_MERCHANT_ID` و `APP_URL` را تنظیم کنید؛ آدرس بازگشت درگاه `APP_URL/api/pay/callback` است.

## دیزاین سیستم

- تم **سرمه‌ای شیشه‌ای** (پیش‌فرض) و تم روشن با دکمه خورشید و ماه؛ انتخاب روی هر دستگاه ذخیره می‌شود
- رنگ‌ها در `src/app/globals.css`: رنگ اصلی مرجانی، و پنج رنگ پاستلی `sand`، `coral`، `mint`، `sky` و `lilac` برای کارت‌ها و برچسب‌ها
- اجزای مشترک در `src/components/ui.tsx`: دکمه، فیلد، کارت شیشه‌ای (`glass`)، `ToneCard`، `Badge`، `Stat`، `Segmented` و چیپ فیلتر؛ پیام شناور با «برگرداندن» در `src/components/toast.tsx`
- انیمیشن‌ها: `animate-rise`، `animate-pop`، `stagger`، `skeleton`، `draw-line` برای نمودار و `animate-ring` برای زنگوله؛ با تنظیم «کاهش حرکت» سیستم خاموش می‌شوند

## تکنولوژی

Next.js 16 (App Router, Server Actions) · TypeScript · Tailwind CSS 4 · PostgreSQL + Drizzle ORM · S3-compatible storage · Vitest

## اجرای محلی

```bash
pnpm install
cp .env.example .env.local        # DATABASE_URL and, optionally, S3 / Kavenegar
pnpm db:migrate
pnpm create-admin "نام" 09120000000 "a-strong-password"
pnpm dev
```

Without Kavenegar keys in development, login codes are printed to the server log. To do the same under `next start`, set `SMS_DRIVER=log`.

## اجرا روی سرور با Docker

```bash
cp .env.example .env              # fill in S3 and Kavenegar values
docker compose up -d --build      # starts PostgreSQL, runs migrations, starts the panel on :3000
docker compose run --rm migrate node node_modules/tsx/dist/cli.mjs scripts/create-admin.mts "نام" 09120000000 "a-strong-password"
```

Put a reverse proxy with HTTPS (e.g. Caddy or Nginx) in front of port 3000. The bucket needs a CORS rule that allows `PUT` from the panel's domain so browsers can upload directly.

## دستورها

| Command | What it does |
| --- | --- |
| `pnpm dev` | Development server |
| `pnpm build` / `pnpm start` | Production build and server |
| `pnpm lint` / `pnpm typecheck` / `pnpm test` | Checks (also run in CI) |
| `pnpm db:generate` | Create a migration after changing `src/db/schema.ts` |
| `pnpm db:migrate` | Apply migrations |
| `pnpm create-admin` | Create or promote an admin user |
